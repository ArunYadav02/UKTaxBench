Models don't say when they're guessing about your tax

UKTaxBench checks language models against a reference implementation of UK income tax, National Insurance and student loan repayment. Every answer has one verifiable number behind it. The interesting result isn't the accuracy column — it's how much of the wrong output arrives with no hint of doubt.

Where it goes wrong

Every case is a payslip line with one right answer. When a model misses, the harness re-runs the calculation under deliberately broken assumptions — last year's thresholds, the allowance taper switched off, the loan ignored — and reports which one reproduces the model's number.

Error attribution

    Reading this

    An unexplained error is a model that produced a number no single wrong rule accounts for. A high explained share is the more troubling finding: it means the failures are systematic and repeatable, not noise.

    By difficulty tier

    Accuracy on L1 is pure recall — no arithmetic, just whether the model knows the threshold. Errors there cannot be blamed on calculation.

    Not tax advice. The reference implementation is a benchmark artifact modelling the common PAYE case on an annual basis. It omits directors' NI, per-period NI, marriage allowance and much else.
